## Objective
Create a travel poster or composite using at least three photographs on separate layers, masks, a suitable background, text, and a layer style.

## Tools Used
- Move Tool
- Free Transform
- Layer Masks
- Layer Styles
- Text Tool

## Step-by-Step Procedure
1. Create a travel poster using at least three photographs.
2. Place each photo on its own layer and rename layers clearly.
3. Use Layer Masks to blend or conceal parts of the images.
4. Adjust placement with Move and Free Transform.
5. Add a background, title, supporting text and at least one Layer Style.
6. Save the PSD and export the final composition as JPG.
