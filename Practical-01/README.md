## Objective
Understand the Photoshop workspace and practice basic tools by creating a composition with at least three shapes and two colors.

## Tools Used
- Move Tool
- Marquee Tool
- Lasso Tool
- Brush Tool
- Eraser Tool
- Crop Tool
- Shape Tool
- Text Tool

## Step-by-Step Procedure
1. Create a 1200 x 800 px RGB document.
2. Explore the Toolbar, Options Bar, Layers panel, Properties and Menu Bar.
3. Practice Move, Marquee, Lasso, Brush, Eraser, Crop and Shape tools.
4. Create a composition with at least three shapes and two different colors.
5. Add the student name, roll number and course using the Text Tool.
6. Save the editable PSD and export the final composition as JPG.
