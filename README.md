## Overview
This repository is organized for six Adobe Photoshop practicals. Each practical folder contains a visual reference export and a README with the objective, tools and workflow.

> **Important:** The included JPG/PNG files are visual reference images cropped from a concept sheet. They are not substitutes for original practical work. Open each practical in Adobe Photoshop, recreate the design with editable layers, and save the required PSD and final export before submission.

## Practicals
1. Photoshop Interface and Basic Tools
2. Photo Editing and Basic Retouching
3. Layers, Masks and Creative Composition
4. Advanced Selection, Color Correction and Adjustment Layers
5. Filters, Effects, Custom Brushes and Blending Modes
6. Complete Photoshop Project — Promotional Poster
