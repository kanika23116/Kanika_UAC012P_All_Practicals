1. Choose a college event, workshop, hackathon, cultural fest or photography exhibition.
2. Include event name, date/time, venue, organizer/department and relevant images.

4. Add an Adjustment Layer and use an advanced selection technique.
5. Apply at least one Filter, one Blending Mode, one Layer Style and a custom brush effect.
6. Organize layer names, save the PSD and export the final poster as JPG.
