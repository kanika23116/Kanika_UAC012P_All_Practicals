## Objective
Create a 1200 x 800 px artwork using at least two filters, a custom brush, at least two blending modes, a layer style, and creative text.

## Tools Used
- Gaussian Blur or another suitable filter
- Camera Raw Filter where available
- Custom Brush
- Multiply
- Screen or Overlay
- Layer Styles

## Step-by-Step Procedure
1. Create a 1200 x 800 px document and suitable background.
2. Apply at least two Photoshop filters.
3. Create or import a custom brush and use it creatively.
4. Apply at least two blending modes, such as Multiply, Screen, Overlay or Soft Light.
5. Apply at least one Layer Style and add creative typography.
6. Keep major elements on separate layers, save PSD and export PNG.
