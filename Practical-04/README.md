## Objective
Select a clearly identifiable subject, refine the edges, use at least two adjustment layers, and control the corrections with a layer mask.

## Tools Used
- Quick Selection, Magic Wand or Lasso
- Select and Mask
- Hue/Saturation Adjustment Layer
- Levels or Brightness/Contrast Adjustment Layer
- Layer Masks

## Step-by-Step Procedure
1. Open a photograph with a clearly identifiable subject.
2. Select the subject using Quick Selection, Magic Wand or Lasso.
3. Refine the selection for clean edges.
4. Create at least two adjustment layers, such as Hue/Saturation and Levels.
5. Use layer masks to control the adjustments and show original versus edited.
6. Save the PSD and export the final image as JPG.
